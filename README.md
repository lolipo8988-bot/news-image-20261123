A one-page newspaper front page summing up Monday 23 November 2026, drawn
fresh with Python + PIL (final edition, `draw_final.py`). The program
(`main.ts`) copies `entry.png` to `/output/entry.png`. The layout follows the classic
front-page formula: a serif masthead with the date as the hero, a
key-numbers strip, three illustrated lead stories, nine small cards each
with its own visual, and a world map with pins plus a briefs column.
